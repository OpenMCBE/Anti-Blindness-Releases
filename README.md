# Anti-Blindness-Releases

A simple mod that removes the blindness effect in Minecraft Bedrock Edition (Android).

## Features

- Removes blindness effect
- Supports v26.2.1

## Requirements

- [LeviLauncher (Android) ](<https://github.com/LiteLDev/LeviLaunchroid>)

## Installation

1. Download `libAntiBlindness.so` from [Releases](https://github.com/OpenMCBE/Anti-Blindness-Releases/releases)
2. Install LeviLauncher.
3. Add the `libAntiBlindness.so` mod in LeviLauncher.
4. Launch Minecraft through LeviLauncher.
